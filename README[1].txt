EYESEE-AI — 10 MIN PRESENTATION BUILD

1) Extract this ZIP.
2) Double-click start.bat.
3) The browser opens automatically at http://127.0.0.1:8788/

IMPORTANT: Do NOT open the HTML by double-clicking it.
The Python backend serves the frontend and API on the same local address.

Backend API: /api/health, /api/patients, /api/screenings, /api/referrals, /api/dashboard, /api/analytics
Database: data/eyesee.db (SQLite)

Prototype note: AI grading is a demo/prototype flow, not a clinically validated diagnostic model.
